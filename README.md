# Portfolio Web Personal - Máximo Augusto Closs

## Descripción del Proyecto
Este es mi portfolio web personal desarrollado para la Actividad Integradora de la Unidad 3. El sitio presenta mi perfil como Estudiante de Tecnicatura en Gestion de Software e Innovacion Tecnologica, además de mi experiencia como Instructor de Robótica. Muestra mis proyectos destacados (como Yerbatera, YaPark y desarrollos en Arduino) y mis conocimientos técnicos.

## Tecnologías Utilizadas
El proyecto fue construido desde cero utilizando:
* **HTML5**: Estructura del sitio con etiquetas semánticas (`<header>`, `<main>`, `<section>`, etc.).
* **CSS3**: Diseño visual, variables CSS, Flexbox para la navegación, CSS Grid para la galería de proyectos y Media Queries para el diseño responsive.
* **JavaScript (Vanilla JS)**: Manipulación del DOM, eventos de usuario y validación del formulario de contacto.

## Principales Funcionalidades
* **Diseño Responsive**: Adaptable a dispositivos móviles y computadoras de escritorio.
* **Modo Oscuro/Claro**: Botón interactivo en la navegación para cambiar el tema visual del sitio usando emojis (☀️ y 🌙).
* **Validación de Formulario**: Comprobación mediante JavaScript de que los campos del formulario de contacto no estén vacíos antes de mostrar el mensaje de éxito.
* **Navegación Interna**: Enlaces ancla en el menú superior para desplazarse suavemente por las diferentes secciones del sitio.

## Instrucciones para visualizar el proyecto
No es necesaria ninguna instalación compleja. Para visualizar el proyecto:
1. Clonar o descargar este repositorio en tu computadora.
2. Asegurarse de que la carpeta mantenga la estructura original (`css/`, `js/`, `img/`).
3. Abrir el archivo `index.html` en cualquier navegador web moderno (Chrome, Edge, Firefox).
